Glossary

Every term the course uses, in one place. Each entry links to the topic that actually explains it — treat this as the index page you scan when a word you half-remember shows up.

Read

The machine

TermOne lineTopic
HLEHigh-level emulation — reimplement the interfaces the game calls, not the hardware. KytyPS5 is HLE.01
LLELow-level emulation — reproduce the machine itself and boot real firmware on it.01
ABIApplication binary interface — the rules for how functions pass arguments and return (which registers, who cleans the stack).03, C2
System V / Microsoft x64The two calling conventions that disagree here — the PS5 uses the former, Windows the latter. KYTY_SYSV_ABI/KYTY_MS_ABI bridge them.03
Guest / HostGuest = the console world the game lives in. Host = your PC. The emulator maps guest things onto host things.01
TLSThread-local storage — per-thread memory reached through a segment register (fs/gs).11
kqueueFreeBSD's unified event mechanism the PS5 exposes — the basis of eventQueue.cpp.12, C4
Fiber (ULT)A user-level cooperative thread — many lightweight stacks switched by hand on one host thread. libUlt.cpp.C2, C4

Loading a game

TermOne lineTopic
ELFThe standard executable format — segments, program headers, dynamic tags. PS5 modules are ELF with Sony extras.05
SELFSony's container around the ELF — decrypted/FSELF modules are what emulators load.05
eboot.binThe main game module — what --game ultimately loads (as /app0/eboot.bin).05
ET_SCE_*The Sony module type tags that make a normal loader reject the file — ET_SCE_DYNEXEC etc.05
PT_OS_DYNLIBDATASony's private segment holding the imports/exports a standard ELF reader never looks at.05
NIDName identifier — a short encoded id (like 0GnN4QCgIfs) a game imports by instead of a function name.07
GOT / PLTGlobal offset table / procedure linkage table — the indirection a dynamic call goes through; the loader rewrites the GOT slot to point at your function.07
RelocationFixing up addresses after a module is placed at a real base address.07
Red zoneThe 128 bytes below rsp System V lets leaf functions use — dangerous on Windows, fixed by redZonePatcher.cpp.C2

Memory

TermOne lineTopic
Guest address / vaddrAn address in the game's virtual memory — an integer throughout the code, a real pointer only at the boundary.C1
Address bandOne of the fixed regions of the guest address space (direct, flexible, pooled memory).09
Page faultA CPU exception on a protected memory access — here, the primary notification channel between CPU and GPU.10
CoherencyMaking CPU and GPU see the same memory — done here by fault-driven upload, not copying.10
16 KB vs 4 KB pagesThe guest believes pages are 16 KB; the host uses 4 KB. The emulator reconciles them at fault time.10
TEBThread Environment Block — Windows' per-thread structure, whose stack limits the guest-stack switch has to hide.C2

Graphics

TermOne lineTopic
PM4The packet format the game writes to tell the GPU what to do — register writes and draws, decoded by the command processor.14
Command processorThe software that consumes the PM4 stream and turns it into Vulkan work.14
Ring bufferThe circular buffer the game fills with PM4 packets, read by the command processor.14
Register stateThe accumulated hardware register writes that become pipeline state — a draw packet itself carries almost nothing.15
SRTShader resource table — where user data SGPRs point, holding the descriptors a shader consumes.15
Descriptor (V#/T#/S#)V# = buffer, T# = sampler, S# = image — the fixed four-dword structs describing resources. Decode them in the Playground.15, P
RDNA2The PS5's GPU architecture — the instruction set the shader recompiler decodes.13
SGPR / VGPRScalar and vector registers in a GPU shader — scalars are per-wave, vectors are per-lane.16
EXEC maskThe register that decides which lanes of a wave execute — every branch in RDNA2 is arithmetic on it.16, L
Wave / wavefrontA group of lanes executing together — the unit of GPU parallelism.16
SPIR-VThe typed, structured shader format Vulkan accepts — what the recompiler emits.13
Dispatcher fallbackWhen control-flow structurisation fails, the recompiler emits one loop over a switch on the program counter instead of proper blocks.16
chksum / shader hashThe value used as the shader cache key — hash in, compiled SPIR-V + pipeline out.C7
Timeline semaphoreA monotonically increasing GPU counter a submission waits on and signals — how CPU and GPU overlap.C4, 17
FenceA per-submission signal that releases retained resources (staging buffers, descriptor sets).C4
Vulkan / MoltenVKVulkan is the host graphics API; MoltenVK provides it on macOS.17

C++

TermOne lineTopic
Translation unitOne .cpp plus its includes, compiled to one object file.C3
ODROne Definition Rule — the reason headers mark shared functions inline.C3
RAIIResource acquisition is initialisation — an object owns a resource and releases it in its destructor.C1
static_assertA compile-time assertion — fails the build, used to lock struct sizes and template contracts.C1
reinterpret_cast"Treat these bytes as this type" — unchecked; the emulator's pointer↔integer workhorse.C1
Move semanticsTransferring ownership instead of copying — std::move/std::forward, the move-only UniqueFunction.C1
TemplateA compile-time factory of functions/classes — non-type parameters, specialisation, constexpr evaluation.C1
constexpr / constevalValues and functions evaluated at build time.C1
thread_localPer-thread storage — how PRINT_NAME traces one thread without locks.C4
EXIT / EXIT_IFThe project's fatal-error macros — report + stack trace + exit 321. No exceptions, no RTTI.C3
LIB_FUNC / LIB_VERSIONThe macros that register an HLE function against a NID in the symbol database.12, C1
KYTY_SYSV_ABIThe per-function attribute that makes a host function speak the guest's calling convention.03

Toolchain

TermOne lineTopic
