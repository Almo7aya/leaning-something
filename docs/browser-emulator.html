      Reading the experiment honestly
      
    
      What is real here—and what is deliberately smaller
      
    
      
      
      Actually happening
      The executable is assembled, mapped and interpreted at runtime. Its memory writes, branch decisions, HLE calls, packets, shader compilations, draw calls, input and save data all drive the visible game.
      
      
      Faithful shape
      The guest/HLE/GPU boundaries mirror KytyPS5: imports become callable targets, game state lives at guest addresses, command packets accumulate graphics state, dirty memory uploads before drawing, and presentation is separate.
      
      
      Intentionally smaller
      The guest ISA is a teaching RISC rather than x86-64, packets are a compact PM4-like subset, and WebGL replaces Vulkan. A browser cannot safely map and execute a real PS5 binary.
