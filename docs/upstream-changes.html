The tree at HEAD

Every source-specific claim on this site is pinned to KytyPS5 main at 5b7d334 (18 September 2026). This page is the reading map for that tree: what lives where, which commits are the evidence, and which topic to open next.

Read

CMake still reports project version 0.3.0; the commit is the pin, not the version string. Counts at this revision: 367 files / 151,906 lines under src/, 16 test executables, ~950 EXIT_NOT_IMPLEMENTED sites, ~500 EXIT sites.

Shader recompiler

Two functions in ShaderRecompiler.cpp are the pipeline. TranslateProgram() (485) runs once per binary: decode (or DecodeFusedProgram for ShaderType::Mesh) → CFG::BuildGraph → structurize or dispatcher fallback → DetectEmbeddedVertexFetch → frontend translate → SSA and simplification → BuildSrtPlan → TrackResources. CompileProgram() (615) runs per resource specialisation: ApplyResourceSpecialization → CollectShaderInfo → AllocateBindings → AnalyzeProgramRequirements → Spirv::EmitProgram. Failures EXIT; nothing takes a std::string* error (af8aecf).

Merged ES/GS geometry stages are Vulkan mesh shaders (3213934, 1fd07c2, spirvEmitterMesh.cpp). The IR keeps an immutable ResourcePlan; Program derives from it. Bindings use DescriptorBindingKind::ShaderData (not a user-data slot name) and Count = 50. The SPIR-V backend is about 404 KB across 18 files. Opcode coverage includes buffer/image atomics, DPP row-xmask, DPP8 moves, dual-source blending, packed-integer negation, S_ASHR_I64, S_WQM_B32, S_ORN2_SAVEEXEC_B32, DS inc/dec-return, and RDNA2 subvector loop masks.

Renderer and host GPU

PipelineStaticParameters is 125 bytes of non-dynamic state, including vk::PolygonMode polygon_mode (50e78d7). Viewport, scissor, depth test/write/compare/bias, the whole stencil state and blend constants are Vulkan dynamic state set per draw (3628d2b); moving stencil to dynamic state shrank the key from 166 to 125 bytes (bce8924). Draw-time flow is ProgramCache::Get → MaterializeResources → CompileProgram on a specialisation miss; a failed materialisation is EXIT_IF.

VMA usage is internal to vma.cpp. Texture-cache work includes DCC clears before binding, DCC reused as HTile, and shared packed texture / render-target channel layouts (a305a6c, textureCommon.cpp). Depth layouts are chosen independently of load clears; overlapping fragment depth feedback is present (2097ebb). PM4 draw arguments collapse into DrawAutoArgs (f27a136); PS5 NGG vertex/instance offsets are applied in DrawAuto (fb4d97e).

Guest GPU

pm4.h is about 60 KB of RDNA 2 fields the PS5 driver actually writes. CB_COLOR0_INFO includes DCC_ENABLE at bit 28. pm4Handlers.cpp is 144 KB; CpOpDrawIndexAuto lives at line 1706. agcRegisterDefaults.inc is 216 KB.

Loader, kernel, common

The TLS patch (5b8e3b5, 2333c23) writes Jit::Call9 as 48 E8 xx xx xx xx 48 89 C0 — a REX.W near call plus mov rax,rax — at inst_ptr after any 0x66 prefixes, so AMD CPUs cannot honour a retained operand-size prefix as callw. POSIX builds install a 64 KB per-thread alternate signal stack (2112424, b61360a).

Unhandled host exceptions print a --- Guest fault context --- block (thread name, 16 registers, code around PC, stack from RSP) then EXIT (c7b0d77, KytyExceptionHandler at runtimeLinker.cpp:782). Three handler branches: illegal-instruction emulation, GPU fault, crash. Guest frame-pointer walks still come from RuntimeLinker::StackTrace() (:1712). Kernel surface includes umtx wait/wake, directory streams shared across seeks and reads (d2fa865), mount-root opens, rwlock variants, and sceKernelClearVirtualRangeName.

HLE libraries

Libs::InitAll (libs.cpp:101) calls each InitXxx_1(s) directly. The registration macros in libs.h are LIB_DEFINE, LIB_NAME, LIB_VERSION, LIB_ADD, LIB_OBJECT, LIB_FUNC. Seventy files, 50,747 lines. Small standalone modules include libCes.cpp (CP932/Shift-JIS ↔ UTF-8, LibCes::InitCes_1), libConvertKeycode.cpp, and libWebBrowserDialog.cpp. Audio uses libs/ajm/decoder.h and 12-channel AudioOut2 downmix. DualSense HIDAPI drives light bar, adaptive triggers, an emulated touchpad and the gyroscope/motion sensors; DualShock 4 uses the same pad path.

Presentation and launcher

The imgui overlay is systemOverlay: IME dialog plus system error dialogs that stay open until dismissed, with controller focus kept. RenderDoc start/stop runs on the present thread (994271e). Escape does not quit the emulator. CLI and launcher both expose --gpu <index> (default -1 = automatic). The Qt launcher has an update checker, a theme, GPU select, linear-image readback, and 720p/1080p/1440p/2160p. Launcher defaults differ from CLI: shader validation on, optimisation Performance; CLI defaults validation off, optimisation None.

Tests and tooling

Sixteen EXCLUDE_FROM_ALL executables (a seventeenth, macos_sse4a_tests, is added on Apple x86-64), ~56,000 lines. Aggregate target kyty_tests. The two heavy files are ShaderRecompilerComputeTests.cpp (1.43 MB) and shaderCfgTests.cpp (640 KB). resource_materialization_tests covers draw-time snapshots. ctest also registers compute_meta_clear_classification.
